# Estella Chart Editor

A community-made visual editor for creating, previewing and sharing custom Estella charts on Windows and native Linux x86_64.

**[Download on itch.io](https://nephxdev.itch.io/estella-chart-editor)** · **[Join the community](https://discord.gg/P3T6wbXpkG)**

## Features

- Editable Game View with Tap, Hold, Risk, Sky, Lite and Critical notes.
- Audio waveform timeline, beat snapping and variable BPM.
- Camera presets, rotation, zoom/depth and scroll preview.
- Copy, paste, mirror, undo/redo and configurable hotkeys.
- Import and export custom song packages.
- English and Turkish interface.

You need your own Estella installation. Direct Test in game is currently supported on Windows only.
