Before you download

A few things to know.

Is this an official Estella editor?

No. This editor is developed by the community and is not affiliated with Imanity Co., Ltd. It is designed for custom charts.

Do I need to own Estella?

Yes. You need your own Estella installation to work with the editor. The editor download does not include the game.

Does the Linux editor need Wine or Proton?

The Linux x86_64 editor runs natively. This is not a Linux port of Estella itself. Direct Test in game is currently supported on Windows only.

Where can I get help or share charts?

Join the Estella Chart Community on Discord for chart sharing, discussion and bug reports. Share only audio and artwork you have permission to distribute.
